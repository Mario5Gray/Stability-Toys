## Public selection and configuration

`--layers` is a comma-separated role list. Recipe `layers` is a JSON list. Image mode defaults to `silhouette`; without an explicit layers selection, retain the current single-SVG image output. An explicit `layers` selection activates the layered bundle, even for `silhouette` alone. Every explicit list must contain silhouette. Accept each name once from `silhouette`, `structure`, `detail`; reject unknown, empty, duplicated, or missing-silhouette lists with exit 2. Normalize publication and result order to that fixed order. Reject `--layers`, role flags, and role recipe objects in standalone modes with exit 2. Reject a role setting when that role is absent from the resolved selection, including the default silhouette-only selection; a successful run must never silently ignore requested public work.

Recipe `structure` and `detail` objects have exactly these optional fields: `source`, `path`, `canny`, `width_mm`, `gap_close_mm`, `include_mask`, `exclude_mask`. `source` is `canny` or `map`. A map requires `path` and rejects `canny`; Canny rejects `path`. Omitted `source` means Canny unless a CLI map chooses map. `canny` has only `low_threshold`, `high_threshold`, and `blur`. Decode paths relative to the recipe directory. Reject unknown fields, wrong types, bool-as-number values, invalid thresholds or blur, and nonfinite/nonpositive lengths through `ConfigError` before artifact publication. Keep schema version 1.

Expose `--structure-map`, `--detail-map`, `--structure-width-mm`, and `--detail-width-mm`. A CLI map selects the map source and replaces that role's recipe Canny configuration. A CLI role width replaces that role's recipe width. Other role options remain recipe-only. `gap_close_mm` has no CLI flag. Preserve the S3.2 interpretation: it is the widest gap to close, `r = max(1, ceil(gap_px / 2 - 1e-9))`, with row and column kernels clamped to canvas reach. Do not turn it into a kernel-width input. Detail must use its own selected Canny values, including the same blur setting used by structure when both use the reviewed shared blur default; do not accidentally drop blur while decoding or resolving detail.

Resolve selected roles into `vector_map_layers.RoleRequest` and call `prepare_layers(settings, requests, input_bytes=snapshots)` once. This returns the S3.1 silhouette and optional S3.2 candidates. Do not recalculate processing size, scale, physical canvas, or origin. An empty optional mask remains selected for diagnostics, but has no SVG file. An empty silhouette remains a processing error.

## SVG and artifact contract

Trace each selected nonempty mask through `vector_map_vtracer.trace_layer`; normalize independently with `vector_map_svg.normalize_svg` and the same `PreparedLayers.canvas`. Keep raw VTracer bytes untouched before normalization. Use `xml.etree.ElementTree` to parse the normalized files and construct `<stem>.svg` with one root carrying their common millimetre width, height, and pixel `viewBox`. Place each layer's children under a named `<g id="silhouette|structure|detail">` in fixed role order. Preserve child paths, transforms, fill, winding, and order. Reject mismatched roots or unsupported content rather than silently adapting geometry. Never parse SVG with a regex.

During an image layered run, write `<stem>.layers/<role>.svg` for each nonempty selected role and the combined `<stem>.svg`. The combined file is for viewing/editing; separate normalized SVGs remain authoritative for SCAD. Make physical root dimensions and origin identical across files. Cover a known rectangle, asymmetric material, donut, nested island, separate components, and border-touching material. Compare rendered hole and alignment results, not just XML attributes.

`Bundle` owns all three fixed layer SVG names on a layered run, even when only silhouette is selected or an optional mask is empty. Reject a symlink `.layers` directory, non-directory path, output/input alias, existing owned file without `--overwrite`, and duplicate output aliases before reading/tracing. Include source, recipe, silhouette mask, global constraints, each external role map, and each role constraint in snapshots and input hashes. Deduplicate reads by path while retaining each input role in the manifest. The raster decoder must consume those captured bytes. `--overwrite` invalidates the old manifest before replacing files; remove owned unselected/empty role SVGs from an older bundle. Preserve unrelated files and the `.layers` directory. Stage bytes before any replacement; publish the manifest last. A failed replacement must not leave a valid completion marker.

Keep current `artifacts.svg`, `artifacts.manifest`, `artifacts.preview`, and `artifacts.debug` path conventions. Add `artifacts.layers` as a role-to-path object containing only files from this run. Report `counts.layers` as the number of published, nonempty layers and sum their path counts. The layered manifest keeps schema version 1, lists selected roles including empty optional roles, and gives each entry `id`, `height_mm: null`, `mode: null`. Preserve the standalone manifest's existing two-field layer entry. Record role requests, resolved Canny values, widths, gap-closing diagnostics, current input hashes, per-layer metrics, combined metrics, and hashes of all published files. Omit timestamps and stale paths. Report empty optional roles as warnings with role names and no exported file.

For `--preview`, create one labeled prepared-mask panel and one rendered-SVG panel per selected role; mark an empty optional role clearly and do not render a nonexistent SVG. Include a source overlay with a legend. Render each published normalized SVG with the existing `resvg-py==0.5.0` pixel-root path; do not derive DPI from millimetres. Preserve deterministic font fallback for Pillow 10.0 or missing FreeType. Keep the existing standalone three-panel preview byte-stable.

For a layered `--debug-bundle`, save a fixed `<role>.png` for each selected prepared mask and a replay recipe in `<stem>.debug/`. Own all three role PNG names. On overwrite, remove unselected role PNGs while preserving unrelated debug files. Hash current debug files in the manifest. Retained debug on tracer/preview failure must not claim a complete bundle.
