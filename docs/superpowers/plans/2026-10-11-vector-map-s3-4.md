## Configuration and geometry

Resolve defaults, recipe, then CLI. Defaults: `export_scad=false`, `center=false`, `detail_mode=raised`, `backing_mm=0`. Without a preset, require positive `silhouette_thickness_mm` for export, plus positive structure/detail heights for their published roles. Reject bool-as-number, nonfinite length, negative backing, unknown recipe fields, and invalid mode through `ConfigError` before publication. Keep schema version 1 and existing exit-code conventions. The later preset will fit between defaults and recipe overrides.

Write `<stem>.scad` beside `<stem>.svg`. Import only `<stem>.layers/<role>.svg` for published roles with `center=false`; never import the combined grouped SVG. Safely quote relative OpenSCAD strings, including filenames containing quotes, backslashes, and non-ASCII. Use S3.3's physical canvas. If centered, apply one outer `translate([-width_mm/2,-height_mm/2,0])` to the whole assembly, never to each import.

Under the Q4 accepted strategy, intersect imported structure and detail with silhouette and subtract structure from detail in 2D. The earlier raster subtraction stays intact; CAD Booleans guard against independently fitted boundary overlap. Name editable parameters B (backing), S (silhouette), H (structure), and D (detail). Nominal Z intervals:

| Element | Z interval |
|---|---|
| Backing, if B > 0 | `[0,B]` |
| Silhouette | `[B,B+S]` |
| Raised structure | `[B+S,B+S+H]` |
| Raised detail | `[B+S,B+S+D]` |
| Engraving removal | `[B+S-D,B+S]` |

Use a documented, bounded small overlap at support planes, without changing top heights or extending below Z=0. For engraving, subtract the detail cutter from the silhouette before unioning structure; extend its top slightly beyond the silhouette and preserve the floor at `B+S-D`. Structure ridges must remain uncut. The optional backing spans the full canvas and joins separate islands. With no backing, warn if the prepared silhouette has multiple raster-connected components, identifying this as an approximation until S3.6 mesh validation. Do not add bridges.

## Bundle and manifest

In every explicit layered run, `Bundle` owns fixed `<stem>.scad`, including runs without export. Without overwrite, refuse an existing owned SCAD file before processing. With overwrite and export disabled, remove stale SCAD after invalidating the old manifest. Protect source, recipe, mask, map, and role constraint aliases; preserve unrelated files. Stage SCAD with SVGs and publish the manifest last. On mutation failure, leave no valid completion marker. A standalone run does not own or clean layered SCAD.

With export, return `artifacts.scad` using the existing artifact path convention and include its current hash in the manifest. Without export, omit that result field and hash. Layered manifest entries keep `id`, `height_mm`, `mode`: published silhouette = S/base, structure = H/raised, detail = D/raised or D/engraved. Empty selected roles and all layers without export have null height/mode. Preserve standalone two-field entries and schema version 1. In layered manifests, always include a top-level `relief` object with exactly `export_scad` (boolean), `center` (boolean), `backing_mm` (number), `silhouette_thickness_mm`, `structure_height_mm`, and `detail_height_mm` (resolved number or null), `detail_mode` (`raised` or `engraved`), and `preset: null` until S3.5. Record validated supplied heights even when an explicit `--no-export-scad` suppresses SCAD; per-layer height/mode remain null without export. Preserve standalone manifest shape, existing artifacts, and counts.
