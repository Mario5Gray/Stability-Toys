## Internal contract

Use `vector_map_layers.py` for role requests and prepared candidate masks.
Use frozen request records for `structure` and `detail`.
Use these names across implementation and tests:

```python
@dataclass(frozen=True)
class CannySpec:
    low_threshold: int | None = None
    high_threshold: int | None = None
    blur: int | None = None

@dataclass(frozen=True)
class RoleRequest:
    role: Literal["structure", "detail"]
    source: Literal["canny", "map"] = "canny"
    path: Path | None = None
    canny: CannySpec | None = None
    width_mm: float | None = None
    gap_close_mm: float | None = None
    include_mask: Path | None = None
    exclude_mask: Path | None = None
```

Expose `prepare_layers(settings, requests, *, input_bytes) -> PreparedLayers`.
`PreparedLayers` contains the S3.1 `PreparedRaster` silhouette and optional `PreparedCandidate` values.
Each candidate contains its role, read-only material, expansion, and diagnostics.
All candidates use `silhouette.canvas`. Do not derive another canvas.
Each request names one role and one source: `canny` or `map`.
For a map request, require `path`. Reject `canny` values on a map request.
For a Canny request, reject `path`. Permit omitted Canny values to use role defaults.
Each request may set `width_mm`, `gap_close_mm`, `include_mask`, and `exclude_mask`.
Reject duplicate roles. Normalize selected roles to `silhouette`, `structure`, `detail` order.
The silhouette is required and comes from `vector_map_raster.prepare`.
Do not recompute its canvas, processing size, or physical scale.

Treat maps and constraints as white material at luminance at least 128.
Orient each external image before dimension checks.
Require each oriented map and constraint to match the oriented source dimensions.
Resize binary maps once with nearest-neighbour to the silhouette processing size.
Keep source alpha out of map selection. Warn when map or constraint alpha is ignored.
Use captured input bytes when the caller supplies them.

Validate Canny thresholds as integers with `0 <= low_threshold < high_threshold`.
Validate blur as 0 or a positive odd integer, as `canny_map.validate_blur` does.
Reject booleans as integers. Reject nonfinite or nonpositive `width_mm` and `gap_close_mm`.
Do not use `canny_map.load_image`; it has different orientation and resize rules.
Orient the source first. Composite any source transparency onto opaque black.
Convert to RGB. Resize with Pillow LANCZOS to the silhouette processing size.
Call `canny_map.canny_edges` once on those pixels with `invert=False`.
Interpret returned white edge pixels as material.
Global `--invert` changes only the silhouette method, not Canny or external maps.

Apply each role's include mask, then exclude mask, before gap closing and band expansion.
Leave gaps open when `gap_close_mm` is absent. This is the default.
Otherwise apply one binary closing to the constrained role material.
`gap_close_mm` is the maximum gap width to close. It is not a kernel width.
Do not reuse the `_expand` rounding rule. A closing of radius `r` closes gaps up to `2r` pixels.
Compute `gap_px = gap_close_mm / mm_per_px`. Compute `r = max(1, ceil(gap_px / 2 - 1e-9))`.
Use a square kernel with side `2r + 1`. The achieved maximum gap is `2r * mm_per_px`.
The achieved gap meets or exceeds the request by less than two pixels.
Reject a radius beyond `int32` limits, as `_expand` does.
Use the OpenCV default closing border. It keeps material at the canvas edge.
Report requested gap, `gap_px`, radius, kernel side, and achieved gap in role diagnostics.
Leave the input band unchanged when `width_mm` is absent.
Otherwise reuse `vector_map_raster._expand` with the silhouette `mm_per_px`.
Report the effective `BandExpansion` for each role.
Warn when `width_mm / mm_per_px < 4`. Reuse code `requested_width_below_four_pixels` and name the role.
Apply each role's constraints again after expansion. Exclusion wins both times.
Intersect each optional role with the final silhouette.
Remove final structure coverage from final detail after both optional roles exist.
An empty optional role remains selected but has no material. Report its role in diagnostics.
An empty silhouette remains an S3.1 processing failure.
Mark each final mask array read-only before returning it.
